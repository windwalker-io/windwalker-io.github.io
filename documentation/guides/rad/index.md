# Rapid Application Development with Unicorn

This guide builds a product-management feature on the [Windwalker Starter](https://github.com/windwalker-io/starter). It adds [Unicorn](https://github.com/windwalker-io/unicorn) for admin grids, forms, and CRUD workflows, then uses those tools to create a product entity, list, and editor.

The chapters progress from project setup and package installation to a working product list and editor:

1. [Project Setup](./project-setup)
2. [Install the Unicorn Package](./unicorn-installation)
3. [Entities, Migrations and Seeders](./modeling)
4. [Admin Grid](./admin-grid)
5. [Advanced Grid Features](./advanced-grid)
6. [Edit Forms and Saving](./edit-forms)

The examples assume a fresh local development database. Commands that reset migrations or seed data can remove existing data; use them only with a disposable database.
